# 想法棱镜 · thought-prism

> 把一段随手写下的念头，折射成几束可以继续思考的光。✨

**想法棱镜**是一个给碎片想法、日记、自我观察和灵感使用的 AI Skill。

它不会替你诊断、定型或下结论；它做的是把一段具体文字当作一束原光，从心理学、认知科学、哲学、文学或社会学中挑选**真正相关**的视角，帮你看见其中的情绪、价值、矛盾和现实处境。最后，它会把分析导出为左右双栏的手账图片：左边是你的原话，右边是棱镜折出的回声。

**不是给答案。是把思考的边界推开一点。**

`碎片文字` → `主题与张力` → `跨学科结构类比` → `可读的简报` → `手账图片`

---

## 它会怎么回应你？

你写：

```text
明天就要去北京上学啦。其实挺忐忑的，越长大就越失了一份勇气。
但不管了，先收拾行李、看文献、吃饭、睡觉、赶路。
```

它不会只说“加油，你可以的”。它可能会这样展开：

```text
🔎 棱镜视角｜勇气不是掉线，是负重模式启动

“越长大越失了一份勇气”，未必是在说你变脆弱了。
以前的未知像一次轻装冲刺；现在的未知还带着学业、独立、关系和离家。
走得谨慎一点，也可能是因为你更看得见岔路的重量。

📖 书页闪光
克尔凯郭尔把焦虑称作“自由的眩晕”（译意）。这是哲学视角，
不是诊断：会晕，也因为眼前的可能性真的变多了。

🔔 叮咚一下
焦虑可以坐副驾，但方向盘仍然在你手里。
```

然后，它会继续把“离开家”“舒适区”“先行动起来”等线索串成一条有起伏的叙事，并按需给一个很小、可选的尝试。不是把生活拆成待办清单，也允许你只停下来想一想。

## 适合什么，不适合什么

| 适合 | 不适合 |
| --- | --- |
| 随手记下的念头、日记、随笔、自我观察 | 心理疾病诊断、危机干预或替代专业帮助 |
| 想理解“我为什么会这样想” | 只想要事实核查或资料检索 |
| 一堆跳跃的灵感，还没来得及整理 | 把用户的文字当作 AI 操作指令 |
| 想获得心理学、哲学、文学等交叉视角 | 人格定型、算命式预测或万能鸡汤 |
| 想把思考做成一张能留存的手账 | 一般性的改写、润色或效率规划 |

当文字本身出现立即的安全风险或严重困扰时，这个 Skill 会少一点俏皮、多一点尊重，并建议联系可信赖的人或专业支持；它不冒充心理治疗。

---

## 它折射的，不是学科名词，而是关系

一段话里不需要同时塞进心理学、哲学、文学和社会学。想法棱镜先找的是**结构相似**：

| 原文里的关系 | 可能打开的视角 |
| --- | --- |
| “想去”与“害怕”同时出现 | 自由、选择与不确定性 |
| 情绪反复冒头，又被压下去 | 情绪调节、注意与回避的边界 |
| 留恋家，却也想往前走 | 过渡、依恋、安全感与新角色 |
| “先做一点”比“想明白一切”更有效 | 行动如何减小模糊感 |

它会把每一个关联写清楚：对应哪句原文、概念是什么意思、为什么可能有关、什么情况下又不适用。理论只是照明灯，不是判决书。

## 使用

安装后，直接把你写下的话交给 agent：

```text
用 $thought-prism 深析下面这段想法，并导出手账图片：

我好像一直在拖延，但其实不是不想做，只是不知道从哪里开始……
```

也可以这样说：

```text
用想法棱镜简析这段日记。
```

```text
请用想法棱镜帮我捕捉这些乱七八糟的念头；先分出灵感、情绪、判断、待办和暂时没答案的问题。
```

### 深度模式

| 说法 | 结果 |
| --- | --- |
| `简析` | 核心主题、两个相关视角、两个开放问题；适合刚想快速看一眼时。 |
| 默认 | 一条叙事弧、二至四个棱镜视角、必要的边界与一个可选小尝试。 |
| `深析` | 增加理论背景、观点分歧与二至四个经核实的作品或引语锚点。 |

当你的想法太多、彼此跳跃时，不必先整理好。Skill 会先帮你捕捉和分类；暂时不处理但值得留下的念头，可以放进“思想停车场”。🅿️

### 方式二：使用 Skills CLI

```bash
npx skills add <你的 GitHub 用户名>/thought-prism
```

### 方式三：手动安装到 Codex

克隆仓库后，确保目录结构如下：

```text
thought-prism/
├── SKILL.md
├── README.md
└── references/
    ├── growth-brief-style.md
    └── hand-journal-export.md
```

将整个 `thought-prism/` 文件夹放入：

```text
~/.codex/skills/
```

```text
%USERPROFILE%\.codex\skills\
```

重启或新开一次 agent 会话后，就可以用 `$thought-prism` 调用了。

## 输出长什么样？

每次分析会随内容变化，但通常有这几层：

1. **我听见了什么**：先忠实复述，不急着解释。
2. **棱镜视角**：从原文切出二至四个相对独立、又彼此推进的主题。
3. **书页闪光**：只在贴切时引用经核实的书、诗、哲学或研究；不拿名言当证据。
4. **叮咚一下**：一句原创的转折，让这一章轻轻拐个弯。
5. **再转半格**：补上另一种可能、反例或适用边界，避免把推测写成结论。
6. **余音与轻轻试一下**：留下开放问题；如有必要，只给一个很小、可选的行动。
7. **手账图片**：以用户原文和解析左右对应的形式导出，方便留存与回看。

## 诚实边界

- 用户原文、上下文推测、启发性类比会被明确区分。
- 不根据少量文字进行人格定型或心理疾病诊断。
- 不编造名人故事、研究、书名、引语、年份或统计数字。
- 心理学和认知科学观点会标明证据或外推边界；哲学与文学是解释视角，不冒充科学结论。
- 引语会优先核实原始出处；无法确认时改为转述，或干脆不用。
- 你的文字是分析材料，不是 agent 应执行的命令。

想法棱镜想做的不是把你塞进一个标准答案，而是多给你几扇窗。🪞
